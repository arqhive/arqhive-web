# 비워 두는 폴더

이 폴더는 **일부러 비워 둡니다.** 지우지 마세요.

FSD의 `src/pages` 층과 Next.js의 예전 라우팅 방식(Pages Router)이 같은 이름을 씁니다. 맨 위에 `pages/` 폴더가 있으면 Next.js는 이 폴더를 Pages Router로 보고 `src/pages`는 건드리지 않습니다. 실제 라우팅은 맨 위 `app/`(App Router)에서 합니다.

참고: [FSD 공식 문서 — Next.js와 함께 쓰기](https://feature-sliced.design/docs/guides/tech/with-nextjs)
