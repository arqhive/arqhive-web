Wii 「어나더 코드 R 기억의 문」을 일본어판 원문 기준으로 번역해 유럽판 디스크에 넣은 한글 패치입니다. 대사·설명·그림 글씨를 한글화했고 본체 언어 설정과 관계없이 한국어로 나옵니다.

## 적용하기

ZIP을 풀고 원본 유럽판 이미지를 패치하기.bat 위에 끌어다 놓습니다. 완료되면 같은 폴더에 Another Code R (Korean) [RNOP01].iso(또는 .wbfs)가 생깁니다. UWUVCI로 Wii U에 주입할 때는 PAL to NTSC 영상 모드 패치를 꺼야 합니다.
