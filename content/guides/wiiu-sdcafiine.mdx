> 넣을 경로(타이틀 ID 폴더)는 게임마다 다르니 각 패치의 README를 봅니다.

## 한글판 파일 만들기

1. 패처 ZIP을 폴더째 풉니다.
2. 원본 게임의 데이터 파일(또는 폴더)을 `패치하기.bat`에 끌어다 놓습니다.
3. `out`(또는 `출력`) 폴더에 한글판 파일이 생깁니다.

## 실기(Aroma + SDCafiine)

- 결과 파일을 SD 카드의 `wiiu/sdcafiine/<타이틀 ID>/<이름>/content/` 아래에 넣습니다.
- Aroma에서 SDCafiine을 켠 채 게임을 실행합니다.

## Cemu

- 결과 폴더를 Cemu의 `graphicPacks` 폴더에 넣고, 그래픽 팩 목록에서 켭니다.
