# ADR (설계 결정 기록)

"무엇을 왜 그렇게 정했는가"를 결정 하나에 문서 하나씩 남깁니다. 결정이 바뀌면 기존 문서를 고치지 않고, 새 ADR을 쓰고 기존 문서의 상태를 "대체됨"으로 바꿉니다.

## 양식

새 ADR은 아래 양식으로 씁니다. 파일 이름은 `번호-짧은-영문-이름.md`입니다.

```markdown
# 0000. 제목(결정을 한 문장으로)

- 상태: 제안 | 채택 | 대체됨(→ 0000)
- 날짜: YYYY-MM-DD

## 맥락
어떤 상황과 제약이 있었나

## 결정
무엇으로 정했나

## 검토한 대안
무엇을 왜 버렸나

## 결과
좋아지는 점, 감수할 점
```
