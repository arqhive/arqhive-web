# 0002. 무료 서버리스로 운영한다

- 상태: 채택
- 날짜: 2026-10-03

## 맥락

- 개인이 만든 한글 패치를 소개하는 사이트라 수익이 없다. 운영비는 0원이어야 하고, 오래 방치해도 돈이 나가지 않아야 한다.
- 규모가 작다(작품 수십 개, 제보 수백 건).
- 직접 관리해야 하는 서버가 생기면 보안 업데이트와 장애 대응이 혼자의 몫이 된다.

## 결정

- 프론트는 **Vercel Hobby**(Next.js), API·작업 큐·정기 작업·AI는 **Cloudflare Workers 무료 플랜**(Hono, Queues, Cron Triggers, Workers AI, Vectorize), DB는 **Neon 무료**(Postgres)를 쓴다.
- 패치 파일은 각 패치 저장소의 **GitHub Releases**에 두고 사이트는 링크만 건다.
- 한도를 넘으면 요금이 붙지 않고 멈추는 서비스만 쓴다. 처음에는 카드 등록도 하지 않는다.
- 주소는 무료 주소(`arqhive.vercel.app`)를 쓴다.

## 검토한 대안

- **AWS(SST + Lambda 등)**: 2025년 7월 개편 후 새 계정은 크레딧과 6개월 무료 플랜을 받고, 이후 유료 전환이 필요하다. 영구 무료로 운영할 수 없다.
- **Oracle Cloud 무료 VM + Docker**: 검색 엔진·통계·관측 도구를 직접 띄울 수 있지만, 이 규모에서는 모두 서버리스나 무료 서비스로 대신할 수 있다. 로컬에만 Docker를 두는 건 보여 주기식이라 의미가 적다. 또 무료 한도가 예고 없이 줄었고(2026-06-15, 4코어·24GB → 2코어·12GB), Tunnel·도메인·보안 업데이트 같은 관리 부담이 크다. 나중에 운영 경험이 필요해지면 붙일 수 있게 `project-plan.md` 12장에 남겨 둔다.
- **Cloudflare R2(파일 저장)**: 무료 한도는 넉넉하지만 넘으면 과금되고 카드 등록이 필요하다. 작품 이미지는 저장소와 Vercel 정적 파일로 충분하다.
- **도메인 구매**: 메일 발송 때문에 검토했으나 회원 기능을 빼면서 필요 없어졌다(0004).

## 결과

- 운영비 0원, 관리할 서버 없음.
- 무료 한도(Workers 요청당 CPU 10ms, Cron 5개, Queues 하루 1만 작업 등) 안에서 설계해야 한다. 한도 수치는 바뀔 수 있으므로 결정에 쓰기 전에 확인하고 날짜를 적는다.
- Vercel Hobby는 비상업용이라 후원·광고를 달 수 없다.
