# 0009. 디자인 토큰은 2안 "기록보관소"로 한다

- 상태: 채택
- 날짜: 2026-10-03

## 맥락

진열장 콘셉트(0008)를 칠할 색·글꼴·모서리를 세 후보로 비교했다. 같은 부품(헤더, 선반, 표지, 상세 제목, 버튼, 목록 한 줄)을 밝은 화면·어두운 화면으로 칠해 봤다.

| 후보 | 색 | 제목 / 본문 / 번호 글꼴 | 모서리 |
|---|---|---|---|
| 1안 나무 서가 | 종이·나무·먹, 주홍 | 함렛 / IBM Plex Sans KR / IBM Plex Mono | 3px |
| **2안 기록보관소** | 회백 종이·남색 잉크·도장 빨강 | **나눔명조 / 고딕 A1 / IBM Plex Mono** | **0** |
| 3안 게임 설명서 | 흰 종이·검정·청록·노랑 | 검은고딕 / Noto Sans KR / 갈무리 | 6px |

## 결정

- **2안 기록보관소**를 쓴다.
- 색은 의미 단위 변수(`--paper`, `--card`, `--ink`, `--ink-sub`, `--line`, `--shelf`, `--stamp`, `--on-stamp`)로 정의하고, 밝은 화면·어두운 화면 두 벌을 둔다.
  - 기본은 시스템 설정을 따른다. 사용자가 고르면 `<html data-theme="light|dark">`로 덮어쓴다.
  - Tailwind v4의 `@theme inline`으로 토큰을 연결해 `bg-paper`, `text-ink`처럼 쓴다.
- 기종별 케이스 색(등줄기·표지)은 화면 모드와 상관없이 고정 토큰(`case-gc` 등)으로 둔다.
- 글꼴은 `next/font`로 빌드 때 받아 사이트에 함께 올린다. 모두 SIL Open Font License다.
- 모서리 둥글기는 쓰지 않는다(각진 편집 디자인).

## 검토한 대안

- **1안**: 진열장의 따뜻함과 가장 잘 맞지만, 갈색 계열이 넓게 깔리면 무겁다.
- **3안**: 게임 사이트다운 인상이 강하지만, 노랑 강조색의 대비를 따로 챙겨야 하고 AI 기본 디자인과 거리를 두기엔 화려하다.

## 결과

- "아카이브"라는 이름과 맞는 차분한 인상이 된다. 진열장의 따뜻함은 기종별 케이스 색과 선반이 맡는다.
- 각진 모서리와 괘선 중심이라 shadcn 기본 모양(둥근 카드)과 확실히 구분된다. shadcn은 동작만 가져오고 모양은 이 토큰으로 다시 칠한다.
- 명조 제목은 작은 크기에서 가늘어 보일 수 있어, 제목은 크게(20px 이상) 쓰고 본문은 고딕으로 쓴다.
