# 0008. 디자인은 진열장 콘셉트로 한다

- 상태: 채택
- 날짜: 2026-10-03

## 맥락

- 다른 한글패치 제작자 사이트들은 AI로 만들어서 에셋만 다르고 레이아웃·디자인이 거의 같다.
- 그런 디자인이 닮아 보이는 이유는 기본값을 그대로 쓰기 때문이다: 어두운 배경과 보라·파랑 그라데이션, 반투명 유리 카드, 가운데 큰 제목 + 기능 카드 세 개 + 카드 격자, shadcn 기본 모양, Inter·Pretendard, `rounded-2xl`, 이모지, 뜻 없는 페이드 애니메이션.
- 운영자는 원래 "진열장에 꽂힌 게임을 누르면 케이스가 열리고 디스크·팩이 보이며 패치로 이어지는" 그림을 구상하고 있었다.

## 결정

- 세 시안을 비교했다: A 기록보관소(도서관 목록 카드, 분류 번호, 표 중심), B 번역 작업대(원문/한글 대조, 글리프 격자), C 진열장.
- **홈은 C 진열장**, **목록 보기는 A의 표형 목록**, **상세 페이지는 B의 원문/한글 비교**를 쓴다.
- 진열장 수정판의 요소: 최신작은 표지가 보이게 진열, 넓은 등줄기와 큰 글자, 기종 필터, 누르면 케이스가 앞으로 나와 열리고 속지에 패치 정보가 보임.
- 시안은 **느낌만 가져간다.** 실제 디자인은 참고 자료 → 흑백 와이어프레임 → 디자인 토큰 → 대표 장치 시제품 순서로 만든다.
- 시안 파일: `docs/design/concept-c-shelf.html`(확정 방향), `concept-a-archive.html`, `concept-b-workbench.html`

## 검토한 대안

- **C 1차 시안(정보를 책장 아래에 표시)**: 본 정보가 책장 밑으로 밀리고, 책장의 등줄기 글씨가 잘 안 읽혔다.
- **A나 B만 쓰기**: 차분하고 쓰기 편하지만 첫인상과 기억에 남는 장치가 약하다.

## 결과

- 사이트마다 비슷한 AI 기본 디자인에서 벗어나고, 운영자의 구상이 대표 장치가 된다.
- 지킬 것
  - 케이스는 기종 느낌만 낸 일반 도형으로 만들고 닌텐도 로고·고유 디자인은 따라 하지 않는다.
  - 박스아트는 저작권 때문에 쓰지 않는다.
  - 휴대폰에서는 선반을 가로로 넘기거나 목록 보기를 기본으로 한다.
- 진열장은 작품이 많아지면 찾기 불편하므로 목록 보기 전환이 꼭 필요하다.
- 디자인 결정은 이후 ADR과 `/colophon`(판권면) 페이지에 남긴다.
