# 0017. 제보 처리 에이전트를 직접 만든다(도구 호출 루프 + 사람 승인 + 평가)

- 상태: 채택
- 날짜: 2026-10-07

## 맥락

- 모델 API를 한 번 부르는 데서 그치지 않고, **스스로 도구를 골라 여러 단계로 판단하는 루프**를 프레임워크 없이 직접 설계·구현하고 평가로 측정한다.
- 처음엔 방문자 질문에 답하는 상담 에이전트(A안)를 검토했다. Workers AI 무료 한도(하루 1만 뉴런)로는 하루 30개 남짓만 답할 수 있고, 아무나 부를 수 있어 남용 방어가 많이 필요했다.
- 제보는 하루 몇 건이라 한도 걱정이 없고 큰 모델을 쓸 수 있다. 분류·중복 찾기·첫 답변은 운영자가 매번 하던 일이라 실제로 쓸모 있다.
- 운영비 0원(0002). 무료로 쓸 수 있는 모델만 쓴다.

## 결정

### 흐름
```
새 제보 → GitHub 이슈 생성(지금처럼) → 뒤에서(waitUntil) 에이전트 실행
  루프(최대 6단계): 모델이 다음 할 일을 고름 → 도구 실행 → 결과를 붙여 다시 모델로
  → submitProposal(처리안) → 코드가 처리안 검증 → Neon agent_runs에 기록
  → 디스코드 "🤖 처리안" + [적용] [무시] (서명 링크)
[적용] → 라벨 붙이기 + 답변 댓글(중복이면 원래 이슈 안내)
```

### 도구
| 도구 | 하는 일 | 데이터 |
|---|---|---|
| `getPatch` | 버전·원본 판·방식·구동 확인 표·알려진 문제 | @arqhive/content |
| `searchSimilarReports` | 의미가 비슷한 지난 제보(자기 자신 제외) | Neon **pgvector**(제보마다 bge-m3 임베딩) |
| `searchGuides` | 관련 가이드·FAQ 문단 | Neon pgvector(콘텐츠 문단 임베딩, 하루 한 번 바뀐 것만 다시) |
| `submitProposal` | 최종 처리안 제출(구조화 출력) | — |

처리안: 분류(오역·미번역·글자 깨짐·실행 문제·기능 요청·질문·스팸), 중복 후보(이슈 주소), 일치하는 알려진 문제, 옛 버전 사용 여부, 답변 초안(해요체 3~6문장), 확신도, 판단 근거 한 줄.

### 검증(코드가 한다)
- 중복 후보는 이번 실행의 `searchSimilarReports` 결과에 있는 이슈여야 한다. 알려진 문제는 `getPatch` 결과에 있는 문장이어야 한다.
- 위반이면 그 칸을 비운다(지어낸 근거 막기). 최대 단계를 넘으면 "판단 보류" 처리안.
- 세 갈래로 나눈다(v3에서 정함).
  - **오류**(분류가 목록 밖, 답변이 빔): 쓸 수 없다. 한 번 다시 쓰게 하고 또 틀리면 판단 보류.
  - **고칠 점**(합니다체, 옛 버전인데 최신 버전을 안 알림, getPatch를 안 봄, `likelyDuplicate` 결과를 무시): 한 번 다시 쓰게 하고, 또 남으면 받되 "남은 문제"로 기록한다(운영자가 본다).
  - **바로잡기**(근거 없는 중복·알려진 문제): 코드가 지운다.
- 숫자 비교 같은 판단은 지시문보다 도구가 판단 재료를 주는 쪽이 잘 지켜진다(유사도 0.8 이상이면 `likelyDuplicate: true`). 도구 호출을 글(JSON)로 써 버린 응답도 어댑터가 살린다.
- 제보 본문은 남이 쓴 글이라 `<report>` 안의 **데이터**로만 다루고, 그 안의 지시는 따르지 않게 시스템 지시로 못 박는다(프롬프트 인젝션). 평가에 인젝션 사례를 넣어 확인한다.

### 사람 승인
- 에이전트는 GitHub에 직접 쓰지 않는다. 디스코드 처리안의 [적용]을 눌러야 라벨·댓글이 반영된다. 이슈 닫기·지우기는 할 수 없다.
- 디스코드 웹훅은 버튼 클릭을 받지 못해 **HMAC 서명 링크**를 쓴다. 비밀 키 `AGENT_SIGNING_KEY`.
  - 구현(10/7): 링크는 하나(`/api/agent/review?run&exp&sig`, 72시간). 여는 것(GET)은 **검토 화면만** 보여 주고, 화면의 [적용]·[무시](POST)가 서명을 다시 확인한 뒤 반영한다. 링크 미리 읽기(디스코드·브라우저)로 실수 반영이 생기지 않게 하려고 처음 계획(동작별 링크·24시간)에서 바꿨다. 운영자가 몇 시간 뒤에 볼 수도 있어 72시간으로 늘렸다.
  - 운영자는 화면에서 답변을 고쳐 올릴 수 있다. 상태는 조건부 UPDATE(`pending`일 때만)로 바꿔 두 번 눌러도 한 번만 반영하고, GitHub가 실패하면 `pending`으로 되돌린다.
  - 댓글 끝에 "AI가 쓴 초안을 운영자가 확인해 올린 답변"임을 밝힌다. 스팸은 라벨만 붙인다.
  - `agent_runs.decision`: 올린 답변·라벨·초안 수정 여부(`edited`) → 승인율·수정률을 본다.

### 기록
- Neon `agent_runs`: 제보, 모델, 지시문 버전, 단계별 도구 호출·결과 요약, 처리안, 검증에서 고친 점, 토큰, 걸린 시간, 상태, 시각. 승인율·단계 수를 볼 수 있다.
  - 상태: running(도는 중, 끝나지 않고 남으면 시간 초과로 끊긴 것) → pending(승인 대기) → applied·ignored(검토 화면에서만), failed(오류·보류), skipped(한도·스위치).
- `report_embeddings`(제보 임베딩, 처리안을 낸 **뒤에** 넣어 자기 자신을 찾지 않게), `guide_chunks`(가이드 28문단, 내용 해시로 바뀐 것만 다시 임베딩, 일일 정산 Cron). 문단이 적어 인덱스 없이 전부 비교한다.
- 개발(시험 제보)은 `dry_run`으로 표시하고 검색도 같은 쪽끼리만 한다(Neon 가지가 하나라 운영 DB를 같이 쓴다).

### 비용·시간 한도
- 제보는 하루 50건까지 받지만 70B는 한 번에 약 200~400뉴런이라, 에이전트는 **UTC 날짜별 20회**까지만 돈다(KV). 넘으면 skipped로 기록하고 임베딩만 넣는다. `AGENT_ENABLED`("0"이면 꺼짐)로 바로 끌 수 있다.
- `waitUntil`은 응답 뒤 약 30초까지 살려 둔다. 실측 한 번에 8~13초라 충분하지만, 넘어서 끊기면 기록이 running으로 남는다. 자주 끊기면 Queues로 옮긴다.

### 모델
- 시작: Llama 3.3 70B fp8 fast(도구 호출 지원, 제보가 적어 한도 여유). 평가로 Mistral Small 3.1 24B·Qwen3 30B와 비교해 정한다.

### 평가(eval)
- `apps/api/eval/cases.json`: 가상 제보 30개. 각 사례에 고정된 도구 데이터(비슷한 제보 목록 등)를 함께 두어 **매번 같은 조건**으로 채점한다.
- 섞을 것: 오역·깨짐·실행 문제·질문·스팸, 알려진 문제와 같은 것, 중복, 옛 버전 사용, 지시를 몰래 넣은 글.
- 채점: 분류 정확도, 중복 찾기, 알려진 문제 대조, 옛 버전 판단, 인젝션 저항, 답변에 꼭 들어갈 사실, 검증 통과율, 단계 수·뉴런.
- 실행: 개발 서버(`wrangler dev`, 원격 Workers AI)에 평가 전용 주소(개발에서만 열림)로 사례를 보내고 채점 → `apps/api/eval/results/<시각>-<모델>-<지시문 버전>-<묶음>.json`.
- 결과(llama70b, core 15개): v1 7/15 → v2 9/15 → v3는 v2에서 틀린 6건 모두 통과(전체 재평가는 한도 때문에 다음 날). 실제 모델을 부르므로 손으로 돌린다(CI는 도구·검증 단위 테스트만).
- 운영에서는 **승인율**을 함께 본다.

## 검토한 대안(무료로 쓸 수 있는 것)

| 선택지 | 좋은 점 | 나쁜 점 |
|---|---|---|
| **제보 처리 에이전트(B)** (채택) | 한도 여유로 큰 모델, 남용 걱정 없음, 운영자 일을 실제로 덜어 줌 | 방문자 눈에 보이지 않음 |
| 패치 상담 에이전트(A) | 방문자가 화면에서 바로 쓸 수 있음 | 무료 한도로 하루 30개 남짓, 남용 방어, 틀린 안내의 피해가 방문자에게 바로 감 |
| 프레임워크(LangChain·AI SDK) | 빨리 만든다 | 핵심(루프·도구·검증)이 라이브러리 안에 가려져 직접 다루고 고치기 어렵다 |
| 임베딩을 Vectorize에 | Workers와 붙기 쉬움 | 이미 쓰는 Neon(pgvector)으로 충분 |

## 결과

- 제보마다 처리안이 디스코드로 온다. 운영자는 [적용]/[무시]만 누르면 된다.
- 무료 모델이라 틀릴 수 있다. 사람 승인·코드 검증·평가로 관리한다.
- 루프·도구 구조는 나중에 다른 에이전트(질문 응답 등)에서도 다시 쓴다.
